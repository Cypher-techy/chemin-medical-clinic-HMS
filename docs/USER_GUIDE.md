# User guide
Sign in → Dashboard (live counts). Reception: Patients→Register (duplicate warning means review linked record first) → Reception check-in (queue number) → Triage (vitals, act on warnings) → Clinical (draft encounter, prescribe — acknowledge allergy warnings, sign; amend signed notes only with reason) → Lab (order, collect, enter, verify; critical results notify clinician) → Billing (invoice, record payment; M-Pesa only counts when callback-verified) → Pharmacy (Dispense FEFO; expired stock is automatically blocked). Portal preview shows only what patients may see.
