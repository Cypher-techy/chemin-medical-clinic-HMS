# Architecture
Modular monolith: Next.js (App Router, TypeScript strict) + Prisma ORM. Modules (patients, reception/queue, appointments, triage, EMR, lab, pharmacy, billing, inventory, inpatient, referrals, incidents, HR, notifications, reports, admin, portal, sync) each own API routes under `src/app/api/*`, shared RBAC (`src/lib/rbac.ts`), audit (`audit()` on every mutation), and DB relations (`prisma/schema.prisma`). Multi-facility-ready: Facility→Departments/Users/Beds foreign keys; all records carry facility-scoped parents. Production DB: PostgreSQL (switch provider + DATABASE_URL); local/offline node may run SQLite file or local Postgres with identical schema (avoid Postgres-only types deliberately). Background work (reminders, sync, reports) runs via sync/notification queues (status fields) — swap in BullMQ/Redis worker without changing module APIs.
