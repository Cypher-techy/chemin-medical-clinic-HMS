# Deployment
Envs: development / staging / production separated; secrets via platform secret manager, never committed. Production: switch Prisma provider to postgresql, set DATABASE_URL, run `prisma migrate deploy`, `npm run build`, serve behind TLS reverse proxy with rate limiting + security headers, enable daily encrypted backups + restore drills, health check = GET /login (200) + DB connectivity in monitoring. Local clinic node: same build with local DB + SYNC_MODE=LOCAL_NODE, documented install/backup on-site. Operational note: do not run `next build` while a server instance is actively writing to the same local SQLite DB (page-data collection opens the DB) — stop the instance, build, restart. Health check: `GET /api/health`. Rollback: redeploy previous build artifact; DB migrations must be backward-compatible.
