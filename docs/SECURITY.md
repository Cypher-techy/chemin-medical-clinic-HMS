# Security
bcrypt(12) password hashing, JWT (HS256, 8h, httpOnly, SameSite=Lax, Secure in prod) sessions, login-failure auditing, account suspension, server-side RBAC on every route, Zod validation on registration, Prisma parameterised queries, audit log append-only via API (protect with DB-level revoke in prod), break-glass requires justification + audit + governance review, M-Pesa callback secret + amount match + idempotency, secrets only in env (see .env.example), rate limiting: enable at reverse proxy before go-live. MFA: TOTP (RFC 6238, `src/lib/totp.ts`) implemented — enrol in Admin → My MFA; login then requires a 6-digit code (verified live). Privileged accounts should be required by policy to enrol. Headers/CSP: configure in production proxy. Never expose clinical data via public website; intake endpoint is API-key + request-only.
