# Modules
Foundation: auth/RBAC/audit/admin/settings. Core: patients (duplicate detection+merge investigation via patient record links), reception/queue, appointments, triage, EMR+timeline. Clinical/financial: lab LIS, pharmacy (FEFO, expiry block, partial dispensing), billing/M-Pesa, SHA claims (`InsuranceClaim` prepared-status only — no simulated submission). Extended: inventory/procurement movements+suppliers, inpatient/beds, emergency/referrals, HR/licences, incidents (confidential), IPC via incidents+checklists (settings). Patient/advanced: portal permitted view, notifications, reports, chronic/MCH registers = appointments+diagnosis filters (activate only when clinic verifies services), AI = disabled by default (`AI_ENABLED=false`), provider-agnostic, human-approval-only design. Sync/backup per OFFLINE_SYNC.md & BACKUP_AND_RECOVERY.md.
